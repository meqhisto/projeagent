## 2024-05-18 - Task Toggle Button Accessibility
**Learning:** Icon-only interactive elements in dynamic lists often lack screen-reader context if state changes are purely visual (like toggling an icon). Specifically, task toggle buttons needed dynamic ARIA labels explaining their current state/action to properly assist screen-reader users, combined with `focus-visible` styling for keyboard navigation.
**Action:** When adding or updating icon-only buttons that toggle states within lists or items, always ensure an `aria-label` is dynamically updated (e.g. 'Görevi tamamlandı olarak işaretle' vs 'Görevi tamamlanmadı olarak işaretle') and implement explicit keyboard focus styles (`focus-visible:ring-2`) using project design tokens (like `ring-purple-600` or `ring-[#0071e3]`).
