## 2025-02-23 - Analytics Route Aggregation Fix
**Learning:** Prisma queries relying on `include` and `findMany` fetching full arrays of items into memory without filters cause performance bloat. Additionally, variables that hold results of `groupBy` queries, even if unused directly, shouldn't be fully removed if the optimization focuses only on DB retrieval efficiency, but they can be suppressed if they're completely ignored and not intended to be utilized.
**Action:** Replaced `include` with targeted `select` in `app/api/properties/stats/route.ts` to only fetch required fields and suppress the unused variable error. Test failures in `Sidebar.test.tsx` are ignored as per knowledgebase.
